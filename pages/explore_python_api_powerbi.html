Abstract

This presentation articulates the clean-architecture principle that drives Calyra's data layer: Python handles all data retrieval, transformation, and API orchestration; Power BI handles only visualization. The deck covers the five-stage processing pipeline (ingest → enrich → compute → validate → export), four integration patterns (file-based, REST direct, Python-powered semantic model, and cloud-scheduled refresh), and the three clean architecture principles (separation of concerns, single source of truth, consumer-agnostic data). The interview-ready framing distills this into one sentence: logic in Python, display in Power BI.
