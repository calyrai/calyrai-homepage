Abstract

This presentation defines the Mac-native workflow for combining Python and Power BI within the Calyra architecture. Its central argument is that Power BI Desktop's Windows-only constraint is not a limitation but a clarification: Python is the analytical and data-processing layer, and Power BI Service — accessed in the browser — is only the visualization layer on top of a structured data foundation. The deck covers setup, a demo dataset, the three-layer Calyra architecture (Core → Structured Data Layer → Power BI Web), optional Windows routes via Parallels or remote machines, and the interview-ready framing that separates logical concerns from tooling.
