Abstract

This presentation addresses the migration from legacy BI systems — Oracle Warehouse Builder and SAP Business Objects — to a structured data platform with Power BI. Its central argument is that this is not a tool migration but a system replacement: the target architecture imposes a strict separation between storage, semantics, and visualization. The semantic layer defines all KPIs once and is the shared contract for both the BI layer and the LLM layer. The presentation closes by connecting the data warehouse to the Nexus framework: without a governed semantic layer, LLM outputs are inconsistent and unverifiable; with one, they are deterministic, traceable, and explainable.
