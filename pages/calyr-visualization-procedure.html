Core Philosophy

Visualization is never the source of truth.

The source of truth is Markdown → Semantic Objects → Nexus Runtime.

Everything else is projection: Atlas, Graffiti, Oracle, Website, Reports, and device-specific views.

Reference document: docs/visualization.md.

02
From scientific truth to oracle, each layer has a distinct purpose.

Visualization Layers

Layer Stack

  • Layer 1 Scientific Truth → Plotly
  • Layer 2 Structural Biology → Mol*
  • Layer 3 Workflow Visualization → React Flow
  • Layer 4 Knowledge Graphs → Sigma.js / Cytoscape.js
  • Layer 5 Geographic Mapping → MapLibre
  • Layer 6 Atlas → React Flow + Sigma.js + Neo4j
  • Layer 7 Innovation Graph → Neo4j + Innovation Engine + Sigma.js
  • Layer 8 Knowledge Flows → Three.js (future WebGPU)
  • Layer 9 Oracle → Prediction Layer

The same semantic object can be shown as graph node, workflow step, report block, innovation path, or knowledge flow depending on projection context.

03
Tiered rollout separates immediate delivery from CALYR IP layers.

Technology Stack

Tiers

Tier 1 Immediate: Plotly, Mol*, React Flow, Neo4j, FastAPI, PostgreSQL.

Tier 2 Growth: Sigma.js, Cytoscape.js, MapLibre.

Tier 3 CALYR IP: Three.js, WebGPU semantic fields, Innovation Graph Engine, Oracle Layer.

If only three are chosen for V1: Plotly.js, React Flow, Sigma.js.

Core components: Nexus (runtime), Atlas (knowledge topology), Graffiti (knowledge creation), Innovation Engine (discovery detection), Oracle (prediction layer).
