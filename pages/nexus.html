Nexus — Machine Learning for Scientific Interpretation

The Nexus is the machine-learning core of Calyrai. It transforms experimental data into structured representations that reveal states, transitions, and physical meaning.

What the Nexus Does

DATA → FEATURES → EMBEDDING → INTERPRETATION
  • Data: SAXS, cryo-EM, simulations
  • Features: extracted signal descriptors
  • Embedding: PCA / latent space
  • Interpretation: physical states

Representation Space

The Nexus maps experimental signals into a shared latent space. In this space, structure becomes visible: clusters, transitions, and trajectories correspond to physical states.

Method: Representation → Parameters → Model Coupling

The Nexus separates structure discovery from physical interpretation. Instead of fitting models directly to data, it first extracts stable representations and parameters, which are then coupled through models. 

signal
  → representation (PCA / embedding)
  → flexible reconstruction (frac)
  → parameter extraction
  → model coupling
  → physical interpretation

In this framework, machine learning reveals structure in the data, while physical models operate on extracted parameters rather than raw signals. This avoids premature modeling and ensures interpretability.

Key Idea

Physical models do not directly fit experimental data. They couple parameters extracted from flexible representations.

How to use the map

  • Click a node: expands the constellation from that node.
  • Drag a node: repositions it; edges update live; layout is remembered.
  • Click the Nexus node: returns here (this page).
  • Click a project node link: opens the project documentation page.

The drifting motion is a subtle “alive” signal; dragging always overrides drift for the node you move.

Example: Chromatography

Chromatographic peaks emerge from repeated transport motifs: drift, surface interaction, and trapping. The Nexus captures these dynamics in a representation space, linking microscopic behavior to macroscopic signals.
