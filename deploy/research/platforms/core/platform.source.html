calyr.aí Positioning

A Knowledge-First Compiler for Research Publishing

calyr.aí applies established compiler and model-driven techniques to a less common domain: representing research knowledge as semantic objects that compile into synchronized outputs. 

knowledge
  -> compiler
  -> website | paper | presentation | graph | workflow | code | interactive objects

Established Techniques We Use

  • YAML-first architecture
  • Single Source of Truth (SSOT)
  • Model-Driven Engineering (MDE)
  • Domain-Specific Language (DSL)
  • Compiler-based architecture
  • AST (Abstract Syntax Tree)
  • Multi-target code generation
  • Declarative configuration
  • Component/block-based rendering
  • Schema-driven validation

Where calyr.aí Is Distinctive

The DSL does not only model page structure. It models research semantics and relationships. A single source can describe and synchronize:

Research Objects

  • Project
  • Paper
  • Figure
  • Workflow
  • Dataset
  • Publication
  • Person
  • Presentation

Publishing Targets

  • Website
  • PDF
  • Presentation and poster
  • Grant and documentation assets
  • ReactFlow and graph outputs
  • Storyboard assets

Claim Boundary

We do not claim YAML-first or compiler architecture as novel by itself.

We claim novelty in applying these established methods to a research knowledge graph that compiles to synchronized, multi-modal research outputs.

Canonical Positioning Statement

A semantic, YAML-based domain-specific language for representing research knowledge, compiled into synchronized interactive publications, presentations, software interfaces, and computational workflows from a single source of truth.
