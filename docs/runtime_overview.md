# Runtime

Execution substrate for semantic orchestration

 Runtime is the protected execution layer handling evaluation order, dependencies, and scheduling. It powers projections without exposing private internal assets.

## Capabilities

- Deterministic orchestration and dependency integrity.

- Constraint-aware execution across instrument domains.

- Stable substrate behind Relay-facing publications.
