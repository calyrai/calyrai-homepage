Relay

Public projection layer for semantic outputs

Relay deploys selected semantic state into public-facing surfaces. It synchronizes external representations with the internal model while preserving governance boundaries between private execution and public output.

Why Relay

  • Consistent publication from a single semantic source of truth.
  • Controlled exposure of model state and interpretation.
  • Traceability from rendered output back to orchestration lineage.
