Apply @

Select a named variant of an operator

Concept

Many Nexus operators are families — compute can compute $P(r)$, Kratky plots, distance distributions, and more. The @ operator selects the variant at parse time and returns a stage (a typed function) that can be used in a pipeline.

Signature

op @ arg   →   Stage<T_in, T_out>

Built-in variants

ExpressionInputOutputAlgorithm
compute@prSignal(q-space)Distribution(r-space)IFT via Shannon / BIFT
compute@kratkySignal(q-space)Signal(q-space)$q^2 I(q)$ vs $q$
fit@guinierSignal(q-space)FitLinear Guinier plot, $R_g$, $I(0)$
fit@debyeSignal(q-space)FitDebye chain model
fit@envelopeDistribution(r-space)EnvelopeAb-initio bead modelling (DAMMIF-style)
fit@kineticSignal(time)FitLangmuir 1:1 kinetic model
refine@densityEnvelopeEnvelopeDensity-regularised refinement

Custom operators

Register a new variant in the Python API:

@nexus.operator("fit", "my_model")
def fit_my_model(signal: Signal) -> Fit:
    ...

After registration, fit@my_model is available in all Nexus sessions.
