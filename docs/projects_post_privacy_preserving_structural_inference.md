# Privacy-Preserving Structural Inference

Selective sequence projection for external structural inference.

This gallery entry only exposes the public-facing idea: sensitive sequence regions are transformed into proxy representations before sending data to external structure predictors.

## Public-facing summary

- preserve fold-level structural signal
- obscure exact engineered motifs
- reduce disclosure of proprietary residues and interfaces
- keep the external call limited to the minimum useful information

## What is intentionally not shown here

- exact masking rules
- private residue mappings
- engineering signatures
- project-specific sensitive motifs
- implementation details for protected inputs
