## Flagship Projects

The Atlas is the knowledge infrastructure.

Projects are the practical manifestations of that infrastructure.

Each project contributes data, methods, models, and knowledge objects back into the Atlas.

## SbpA Dynamic Assembly Project

### Flagship Research Program

Understanding biological self-assembly across scales.

The SbpA project explores:

- S-Layer formation
- Lattice emergence
- Symmetry selection
- Dynamic assemblies
- Attractor landscapes
- Hybrid structural reconstruction

The project integrates:

- CryoEM
- SAXS
- Computational modeling
- AI-assisted analysis

This project serves as a flagship demonstration of how experimental observations, computational models, and semantic knowledge structures can be unified.

## Core Facility Data Initiative

### Scientific Knowledge Infrastructure

Modern research facilities generate enormous amounts of data.

Much of this information remains fragmented across instruments, reports, and projects.

The objective of the Core Facility Data Initiative is to transform scientific measurements into connected knowledge structures.

Areas include:

- Structural biology
- Biophysics
- Spectroscopy
- Imaging
- Experimental metadata

The goal is not merely data storage.

The goal is knowledge integration.

## Oracle Project

### Predictive Knowledge Systems

The Oracle Project investigates how patterns can be transformed into predictive knowledge.

The project explores:

- Semantic discovery
- Knowledge-driven prediction
- Pattern recognition
- Biological systems understanding

Specific implementations remain intentionally abstract while the underlying concepts continue to evolve.
