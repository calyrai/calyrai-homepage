# Calyr.aí Engine Project Description

Engine Project Description

## Project Scope

This project defines a reusable engine-page architecture for CALYR workflows.

The first reference implementation is the AlphaFold workflow surface.

The objective is stable visual continuity with internal object-oriented reusability.

## Structural Model

The page is organized through objects rather than static HTML composition.

- CalyrPage as root abstraction
- EnginePage for runtime-specific context
- WorkflowPage for node and edge orchestration
- WorkflowCanvas for interactive graph rendering
- EnginePanel and ProjectionPanel for controls and metadata

## Workflow Stages

The baseline engine flow is represented as ordered stages:

- Sequence Input
- Model Prediction
- Structure Output
- Validation
- Projection

These stages are defined in source configuration and rendered consistently through the same layout shell.

## ASC Integration Surface

ASC integration is treated as a runtime adapter layer.

The adapter prepares submission payloads, preserves provenance, and separates execution concerns from UI concerns.

This keeps the user interface stable while enabling runtime expansion.

## Delivery Rule

No redesign is required for this project description path.

Content evolves through markdown.

Projection evolves through YAML.

Rendering evolves through object-oriented internals.
