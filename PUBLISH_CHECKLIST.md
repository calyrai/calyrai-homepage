# Publish Checklist

Scope: public repository release quality and safety.

## Gate

- [ ] Release status reviewed in RELEASE_STATUS.yaml
- [ ] Target branch confirmed
- [ ] Public pages/docs selected

## Safety

- [ ] No private intake data
- [ ] No internal evaluation outputs
- [ ] No credentials or tokens
- [ ] No local databases

## Content quality

- [ ] Links resolve
- [ ] Project entries visible in navigation
- [ ] Blog index updated where needed
- [ ] Public wording reviewed

## Final

- [ ] Final staged diff reviewed
- [ ] Commit message reflects release scope
