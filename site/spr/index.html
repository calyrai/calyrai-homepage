CALYR Research Journal · SPR Research Series

Measure the surface.
Interrogate the model.

Surface-plasmon-resonance data can support several kinetic explanations. CALYR treats them as competing scientific hypotheses — from simple occupancy models to stochastic and memory-based descriptions — and asks which structure is actually supported by the experiment.

Scientific principle
sensorgram / model class / uncertainty / held-out test / decision

Complexity is not evidence. Every additional state, distribution, memory kernel or stochastic mechanism must improve prediction, calibration, identifiability or experimental discrimination.

01 · deterministic states

Sequential Occupancy

Tests whether multi-step adsorption and shared latent states explain association, dissociation and equilibrium more consistently than simpler alternatives.

02 · stochastic dynamics

Stochastic Oracle

Uses event-level trajectory ensembles as a way to represent kinetic variability and uncertainty when deterministic averages are insufficient.

03 · memory

Kernel Dynamics

Compares finite state-chain, Erlang and fractional-memory descriptions while keeping nuisance effects and transport alternatives explicit.

04 · comparative inference

Model Atlas

Places model families in one comparative space so that assumptions, limits, identifiable parameters and falsification tests remain visible.
