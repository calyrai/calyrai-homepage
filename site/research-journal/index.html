2026-09-28 · SAXS WORK

Model-Aware SAXS from Domain Structure

A hierarchical methods programme separates domain-level spatial learning from SAXS prediction. Domains learn reusable 3D representations from sequence and secondary-structure topology; a separate assembly layer represents relative domain geometry; the SAXS learner then jointly predicts declared model coordinates and low-dimensional residual curve structure.

Workflow

Sequence / Domain / α/β/coil topology / Domain 3D / Assembly / θ_model + residual PCs / SAXS / Benchmark / Biomni / Review

Evidence / decision / next +

Evidence
The strict database lane excludes SAXS-derived Dmax, Rg, I(0), P(r) and Porod volume from predictive inputs. Versioned dataset, domain-spatial and model-aware benchmark contracts exist; numerical performance results are not yet frozen.

Decision
Keep domain-spatial learning as an independent governed module. SAXS consumes only accepted structural states and compares model-only against model-plus-residual prediction on held-out complete curves.

Next
Execute the frozen benchmark, validate domain-spatial targets independently, run structural ablations and freeze results only after scientific review.
