SAXS interface

Drag & drop → Nexus (9000) → BMCA (8002)

Drop an input file into one of the sections below. The interface sends it to Nexus, which routes it to the BMCA engine and returns a pipeline trace + JSON result.

What this does

This is a local UI for running the SAXS pipeline.

When you drop a file, the browser reads it as text, parses it into JSON, then POSTs it to Nexus at http://127.0.0.1:9000/route. Nexus forwards to BMCA at http://127.0.0.1:8002/infer and returns a result.

You’ll see two things in “Results”: (1) a pipeline step trace, and (2) the returned JSON.

I(q) — SAXS curve

Computed from the structure. Local PDB scattering uses a fixed q-range of 0.01 to 5 1/nm.

Wheel to zoom. Drag to move the zoomed view. Shift-drag draws a zoom box.

p(r) — Pair distance distribution

Computed directly from PDB pair distances. The preview is the normalized PDD shape, shown as p(r) / max for fitting.

Wheel to zoom. Drag to move the zoomed view. Shift-drag draws a zoom box. The magenta fit keeps the current view while you drag knots.

PDB — Structure text

Paste PDB text, load by ID, or drop a .pdb onto the text box.
