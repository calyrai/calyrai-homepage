<section id="overview" class="project-section">
  <h3>Overview</h3>
  <p>Vaults turns mail, calendar events and notes into a legible lab narrative. Instead of losing context in threads, it keeps a composable timeline of decisions, datasets and interpretations.</p>
</section>

<section id="methods" class="project-section">
  <h3>Methods</h3>
  <p>The core idea is a stable set of schemas that can be generated from daily workflows and later queried by intent: what was decided, which samples were discussed, and what the latest hypothesis was.</p>
</section>

<section id="position" class="project-section">
  <h3>Constellation Position</h3>
  <p>Vaults is the organizational memory branch of the platform. It keeps scientific context structured while the modelling and interface layers evolve.</p>
</section>
