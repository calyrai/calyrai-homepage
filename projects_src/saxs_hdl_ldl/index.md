<section id="overview" class="project-section">
  <h3>Overview</h3>
  <p>SAXS HDL LDL is the lipoprotein branch of the SAXS program, focused on scattering comparisons across heterogeneous particle classes and structure-to-signal interpretation.</p>
</section>

<section id="scope" class="project-section">
  <h3>Scope</h3>
  <p>The public project node is now in place as a real homepage. The next step is to anchor it to real datasets, comparative protocols and reproducible outputs.</p>
</section>

<section id="position" class="project-section">
  <h3>Constellation Position</h3>
  <p>This branch extends the general SAXS representation logic to a heterogeneous particle problem where class structure matters as much as average signal shape.</p>
</section>
