<section id="overview" class="project-section">
  <h3>Overview</h3>
  <p>The SAXS interface is the operational front door for structure-side inspection: load models, compare measured and calculated curves, inspect P(r), and work with browser-native controls instead of scattered local scripts.</p>
</section>

<section id="workflow" class="project-section">
  <h3>Workflow</h3>
  <p>This page is the project home. The interface itself remains the execution surface, but the homepage now explains the project before users drop into the tool.</p>
</section>

<section id="role" class="project-section">
  <h3>Role</h3>
  <p>The SAXS interface sits between workflow control and exploratory analysis: it is where structural inspection stays fast while the Nexus and BMCA stacks provide deeper orchestration and inference.</p>
