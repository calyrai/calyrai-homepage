<section id="overview" class="project-section">
  <h3>Overview</h3>
  <p>SAXS IGM focuses on immunoglobulin state mixtures, low-resolution envelopes and comparative curve interpretation for heterogeneous solution states.</p>
</section>

<section id="scope" class="project-section">
  <h3>Scope</h3>
  <p>The project is currently staged as a public node and now has a dedicated homepage. The next step is to connect it to active case data and reproducible analysis paths.</p>
</section>

<section id="position" class="project-section">
  <h3>Constellation Position</h3>
  <p>This is a focused application branch under the broader SAXS analysis program, aimed at mixture inference and comparative interpretation of immunoglobulin systems.</p>
</section>
