<section id="overview" class="project-section">
  <h3>Overview</h3>
  <p>The SAXS Viewer is the lightweight visual analysis branch in the Calyr homepage. It gives fast access to scattering interpretation, parameter inspection and direct visual comparison without requiring the full workflow stack.</p>
</section>

<section id="position" class="project-section">
  <h3>Position</h3>
  <p>This project page makes the viewer a first-class project node rather than an orphaned tool link. The viewer remains the live interaction surface, but it now has a stable landing page in the public project layer.</p>
</section>

<section id="role" class="project-section">
  <h3>Role</h3>
  <p>The viewer is the fast visual companion to the deeper workflow and modelling layers, useful when you need immediate curve inspection rather than full pipeline execution.</p>
</section>
