# calyr.ai publication mirror

Canonical website source: https://github.com/ruperttscheliessnig/calyr-lithios-web

`site/` contains the reviewed CALYRAI public build. This repository only publishes that static build to the existing calyr.ai GitHub Pages domain. DNS and email are unchanged.

Previous layout is retained in tag `archive/layout-before-2026-09-29` (commit 25062ea); legacy source files remain for recovery and are no longer built by Pages. Do not edit them to change the active website.

The replacement includes the Research Journal and shared header. Separation is a collapsed secondary application. Protected portals and private research data are not included.
