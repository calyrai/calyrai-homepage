PCA & Free‑Energy Modes

Principal components interpreted as perturbations of G(λ) — a language for cooperative transitions.

Back to Projects Explore Map

Overview

PCA here is not just dimensionality reduction — it is a model for how experiments move through state space. The aim is interpretability: each mode is a candidate mechanism.

Methods

We track changes across conditions using low-dimensional coordinates, then map them back to thermodynamic narratives (stability, cooperativity, transitions).
