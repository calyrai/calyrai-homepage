Overview

SAXS HDL LDL is the lipoprotein branch of the SAXS program, focused on scattering comparisons across heterogeneous particle classes and structure-to-signal interpretation.

Scope

The public project node is now in place as a real homepage. The next step is to anchor it to real datasets, comparative protocols and reproducible outputs.

Constellation Position

This branch extends the general SAXS representation logic to a heterogeneous particle problem where class structure matters as much as average signal shape.
