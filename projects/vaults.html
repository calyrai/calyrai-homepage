Project

Vaults

MailVault / CalVault as a scientific context engine: turn communication into structured traces, then query them like an experiment.

Back to Projects Explore Map

Overview

Vaults is about turning mail, calendar events and ad-hoc notes into a legible lab narrative. Instead of losing context in threads, you keep a composable timeline of decisions, datasets and interpretations.

Methods

The core idea is a small set of stable schemas (YAML vaults) that can be generated from daily workflows and later retrieved by intent ("what did we decide", "what’s the latest hypothesis", "which samples were discussed").

Interactive
