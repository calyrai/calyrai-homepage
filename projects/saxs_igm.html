Overview

SAXS IGM focuses on immunoglobulin state mixtures, low-resolution envelopes and comparative curve interpretation for heterogeneous solution states.

Scope

The project is currently staged as a public node and now has a dedicated homepage. The next step is to connect it to active case data and reproducible analysis paths.

Constellation Position

This is a focused application branch under the broader SAXS analysis program, aimed at mixture inference and comparative interpretation of immunoglobulin systems.
